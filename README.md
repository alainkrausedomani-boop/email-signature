## Install in Gmail

1. Open `alain_signature_preview.html` in Chrome while online.
2. Select only the dark signature card and copy it.
3. In Gmail, open Settings → See all settings → General → Signature.
4. Paste into the signature box and click Save Changes.

`alain_signature_snippet.html` is the same card as HTML, with absolute image URLs, if a mail client asks for source. Do not paste a base64 or data-URI version into Gmail.
